# Monetization Roadmap

## 基本方針

初期は競艇メディアとして、無料SNS投稿、分析レポート、振り返り、改善メモの蓄積に集中します。有料予想販売や自動投稿はすぐに実装しません。

## note

蓄積した分析をもとに、読み物として価値のある研究ノートを作成します。

候補:
- 場別傾向の研究ノート
- 天候別の見方まとめ
- 初心者向けレース観戦ガイド
- 1週間の振り返りレポート

## LINE

無料レポート配布や更新通知の導線として活用します。

候補:
- 週次振り返り
- レース前チェックリスト
- SNSでは出しきれない補足メモ

## Discord

月額コミュニティの基盤として検討します。

候補:
- レース研究チャンネル
- 振り返りチャンネル
- 初心者質問チャンネル
- コンプライアンス注意喚起チャンネル

## YouTubeライブ

ライブ配信は、購入誘導ではなく観戦体験と学習を中心に設計します。

候補:
- レース前の見どころ整理
- レース後の振り返り
- 場別の特徴解説
- 視聴者質問への回答

## アフィリエイト

競艇メディアと相性の良い範囲で検討します。

候補:
- 書籍
- データ分析ツール
- 動画配信関連
- 配信機材

## 横展開可能性

電話占い、占いメディア、他の趣味系サロンなどへの横展開は将来的に検討できます。ただし、初期は競艇メディアに集中します。

## 初期集中領域

- 投稿案生成
- 分析レポート
- コンプライアンスチェック
- PDCA改善
- memory蓄積
