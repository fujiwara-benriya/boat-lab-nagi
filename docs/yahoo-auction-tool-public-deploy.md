# ヤフオク出品CSVツールを誰でも開けるリンクにする

## 結論

`127.0.0.1` や `192.168.x.x` のリンクは、作業PCの中または同じWi-Fi内でしか開けません。

誰がどこで開いても使えるようにするには、`site/yahoo-auction-listing-tool.html` をHTTPS対応の静的ホスティングへ置きます。

## 公開するファイル

```text
site/yahoo-auction-listing-tool.html
```

このHTMLは単体で動きます。サーバー側DBやAPIキーは不要です。

このリポジトリではGitHub Pages用のワークフローを追加しています。`main` に反映されると、以下のURLで開ける想定です。

```text
https://fujiwara-benriya.github.io/boat-lab-nagi/yahoo-auction-listing-tool.html
```

## 使える公開先

- GitHub Pages
- Netlify
- Cloudflare Pages
- 自分のレンタルサーバー

## 重要な仕様

- データと写真は、開いた人のブラウザ内に保存されます
- 公開先サーバーへ出品データや写真は送信しません
- スマホでは `カメラ/写真を開く` から撮影または写真選択します
- CSVは各端末で `CSV出力` します
- 写真は各端末で `画像出力` します

## 運用イメージ

1. HTMLを公開先へアップロードする
2. 発行されたHTTPS URLをスマホで開く
3. `新規商品` を押す
4. `カメラ/写真を開く` を押して撮影する
5. タイトル、状態、サイズ、価格、発送などを入力する
6. まとまったらCSVと画像を出力する
7. ヤフオクまたは一括出品ツールへアップロードする

## 注意

ブラウザの保存領域を使うため、端末やブラウザを変えると保存データは共有されません。複数人で同じ在庫を共同編集したい場合は、別途サーバーDBかGoogleスプレッドシート連携が必要です。
