# プロジェクト概要

「ボート研究室 / 水面解析ナギ」は、ボートレースを無理なく長く楽しむためのデータ活用メディアです。

## 目的

- 水面、風、展示、モーター気配をもとにした分析の蓄積
- 買う判断だけでなく見送り判断をコンテンツ価値にする
- 結果検証を通じて、分析の良かった点と外れた点を記録する
- 健全利用、予算管理、入金限度額設定の啓発を行う

## 2ブランド構成

### ボート研究室

公式サイト、WordPress、データベース、SEO、広告、アフィリエイトを担う。

### 水面解析ナギ

SNS、note、将来のVTuber配信を担う人格・発信ブランド。

## 成功条件

- 煽りではなく、判断材料として信頼される
- 見送り判断が読者の損失抑制と納得感につながる
- 運用者が継続できるデータ取得、記事作成、検証フローを持つ
