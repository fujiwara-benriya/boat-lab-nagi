# note販売計画

## 商品名

水面解析ナギのボートメモ

## 役割

独自データを使った注目レース、見送り判断、結果検証を有料メモとして販売する。

## 基本方針

- 的中や利益を保証しない
- 勝てる、稼げる、必勝などの煽りを使わない
- 生活費とは分けた予算内で楽しむ注意を入れる
- 買う条件だけでなく見送り条件を必ず入れる
- 結果検証への導線を作る
- 有料部分でも不確実性とリスクを隠さない

## 無料部分

- レース概要
- 分析の前提
- 健全利用の注意
- 的中・利益保証がないこと
- 有料部分に含まれる内容の説明
- 見送り判断を重視する姿勢

## 有料部分

- 詳細な水面、風、展示、モーター気配の読み
- 買う場合の条件
- 見送る場合の条件
- リスク要因
- 結果検証で見るポイント
- 予算内利用の再確認

## 価格設計案

- 単発メモ: 低価格から開始し、過度な期待を煽らない
- まとめメモ: 週次の結果検証や場別傾向を中心にする
- 将来の定期購読: 結果検証と見送り判断の継続価値を軸にする

## 販売導線

- X / Threads: 無料部分の要点と注意事項を告知
- WordPress: 関連する無料解説記事から導線を置く
- note: 無料部分で前提、注意、見送り姿勢を明示する
