# WordPressサイト計画

## 役割

ボート研究室の公式サイトとして、検索流入、データベース閲覧、分析記事、健全利用ガイド、広告・アフィリエイト導線を担う。

## サイト方針

- 「当てる煽り」ではなく「長く楽しむための判断材料」を提供する
- 水面、風、展示、モーター気配を軸にする
- 買う理由だけでなく、見送り判断を記事価値にする
- 生活費とは分けた予算内利用を繰り返し伝える
- 的中や利益を保証しない

## 投稿タイプ

### post: 通常記事

用語解説、読み方、健全利用、予算管理、アフィリエイト記事を扱う。

- 主な読者: 検索流入の初心者から中級者
- 主な導線: 用語解説、健全利用ガイド、場別データ
- 注意: 購入額増加ではなく予算管理へつなげる

### race_analysis: レース分析

レースごとの注目点、買う場合の条件、見送り条件を整理する。

- カスタムフィールド: race_id、date、venue_code、race_no、confidence、decision
- 必須セクション: 前提、水面・風、展示、モーター気配、買う条件、見送り条件、注意文
- 注意: 的中や利益を保証しない

### result_review: 結果検証

分析後に、見立てが合っていた点と外れた点を記録する。

- カスタムフィールド: race_id、source_analysis_id、decision、review_status
- 必須セクション: 結果概要、合っていた点、外れた点、次回見る点
- 注意: 都合のよい的中だけを強調しない

### venue_data: 場別データ

場ごとの水面、風、コース傾向、季節性を整理する。

- カスタムフィールド: venue_code、season、sample_size
- 必須セクション: 水面特徴、風の影響、荒れやすい条件、見送り候補条件
- 注意: サンプル数が少ない場合は明記する

### motor_review: モーター評価

モーターやボートの傾向を整理する。

- カスタムフィールド: venue_code、motor_no、period_start、period_end、sample_size
- 必須セクション: 数値傾向、展示で見る点、過信しない条件
- 注意: 数値だけで断定しない

### healthy_play_guide: 健全利用ガイド

入金限度額、別口座管理、予算管理、見送り判断を扱う。

- カスタムフィールド: guide_topic、affiliate_allowed
- 必須セクション: 課題、具体策、注意点、関連リンク
- 注意: アフィリエイトは健全利用の文脈に限定する

## 内部リンク設計

### 基本リンク

- レース分析 -> 関連する場別データ
- レース分析 -> 展示の見方
- レース分析 -> 見送り判断の考え方
- レース分析 -> 結果検証
- 結果検証 -> 元のレース分析
- 健全利用記事 -> 入金限度額設定
- 健全利用記事 -> 別口座管理
- note告知記事 -> 関連する無料解説記事

### ハブページ

- 初心者向け: ボートレースを予算内で楽しむ基本
- 分析向け: 水面・風・展示・モーターの読み方
- 検証向け: 結果検証まとめ
- 健全利用向け: 入金限度額と別口座管理

### 内部リンクの注意

- 「このレースを買うべき」と急がせるリンク文言を避ける
- noteへの導線は、無料部分の価値と注意事項を明示してから置く
- アフィリエイトリンクは、予算管理や別口座管理の説明内に置く

## 広告・アフィリエイト

健全利用と予算管理の文脈に限定する。購入額の増加を煽る導線は避ける。

### 優先テーマ

- 別口座管理
- 家計管理
- 予算管理アプリ
- 入金限度額設定の考え方

### 禁止テーマ

- 借入を前提にした購入
- 高額購入を促す訴求
- 的中率や利益保証を使った誘導
