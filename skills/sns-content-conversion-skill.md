# SNS Content Conversion Skill

## 目的

分析結果をX、Instagram、Threads、note、YouTube向けに変換します。

## 媒体別ルール

X:
- 1投稿1テーマ
- 短く、感情と観点を入れる
- 断定ではなく観察を中心にする

Instagram:
- 1枚目でテーマを示す
- 箇条書きで保存しやすくする
- 初心者向けの言葉を使う

note:
- タイトルは学習、振り返り、研究の文脈にする
- 有料販売を前提にしすぎない

YouTubeショート:
- 冒頭3秒で観点を提示する
- 煽りではなく発見を軸にする

## 共通禁止事項

- 的中保証
- 収益保証
- 過度な購入誘導
- 自動投稿の実行
