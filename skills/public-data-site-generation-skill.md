# Public Data Site Generation Skill

## 目的

競艇データを将来的にデータベース型ホームページへ展開するため、公開用データとページ案を生成する。

## 作業ルール

- 事実データとAI考察を分ける
- 公開用データに非公開研究メモを混ぜない
- 選手、場、コース、決まり手のページを分ける
- 統計はサンプル数つきで表示する
- サンプル不足時は参考値と明記する
- まだ実際の公開はしない

## 生成するページ案

- 選手ページ
- 場別ページ
- コース別成績ページ
- 決まり手分析ページ
- 日次データまとめページ

## 禁止事項

- 未来の結果を断定する
- 成果を約束する
- 非公開メモの混入
- サンプル不足の隠蔽
