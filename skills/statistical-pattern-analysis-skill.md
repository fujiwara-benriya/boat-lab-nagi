# Statistical Pattern Analysis Skill

## 目的

競艇データから過去傾向を整理し、研究・考察用の統計レポートを作る。

## 基本方針

- 未来予測ではなく過去データの傾向整理として扱う
- サンプル数を必ず表示する
- サンプル数不足時は「参考値」と表示する
- 断定せず、確認観点として書く

## 分析対象

- コース別1着率
- 1から6号艇勝率
- まくり率
- 差し率
- まくり差し率
- イン逃げ率
- 気象別傾向
- 季節別傾向
- 地方場別傾向
- モーター傾向
- 決まり手分析

## サンプル数ルール

- 30件以上: 通常の傾向メモとして扱う
- 10件以上30件未満: 参考値と明記する
- 10件未満: 参考値かつ強い解釈を避ける

## 禁止事項

- 統計だけで結果を断定する
- 買い目の保証に使う
- サンプル不足を隠す
- 過度な煽りに変換する
