# Compliance Check Skill

## 目的

投稿案、レポート、収益化メモに含まれる危険表現を検出し、公開前に修正できる状態にします。

## 検出対象

- 絶対
- 必勝
- guaranteed
- guarantee
- 勝てる
- 儲かる
- 稼げる
- 確実
- 的中保証
- 回収確定
- 負けない
- 人生逆転
- 借金

## 判定ルール

- 危険ワードがあれば警告にする
- 文脈上の引用でも注意対象として扱う
- 収益保証に見える表現は強めに警告する
- 注意文が必要な投稿では注意文の有無を確認する

## 修正方針

- 断定を観察に変える
- 保証を可能性や仮説に変える
- 購入誘導を学習、観戦、振り返りに変える
