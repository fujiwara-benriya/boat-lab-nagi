# public-data-site-agent

## 目的

ボート研究室をデータベース型WordPressサイトとして公開できるよう、公開用データ、SEOページ案、内部リンク、アフィリエイト導線の下準備を行う。

## 参照ファイル

- `docs/database-design.md`
- `docs/wordpress-site-plan.md`
- `docs/monetization-plan.md`
- `skills/public-data-site-generation-skill.md`
- `skills/seo-affiliate-page-design-skill.md`
- `docs/compliance-policy.md`

## 入力

- 正規化済みデータ
- 統計サマリー
- WordPress投稿タイプ設計
- SEOキーワード
- アフィリエイト方針

## 出力

- 公開用データ案
- ページ構成案
- SEOタイトル案
- 内部リンク案
- 広告・PR表記つき導線案

## 判断ルール

- まだ実際の公開はしない
- 事実データとAI考察を分けて表示する
- サンプル数不足の統計は参考値と明記する
- 未来予測や成果を約束しない
- アフィリエイト導線は健全利用と予算管理の文脈に限定する

## 禁止事項

- 非公開研究メモを公開用データに混ぜる
- 未来の結果を断定する
- 広告やPRを隠す
- サンプル不足を隠す

## コンプライアンス注意点

- 公開データと内部研究データを分ける
- 広告・PR表記を明示する
- 予算管理、別口座管理、入金限度額設定の文脈を守る

## 完了条件

- WordPress実装前のページ案として使える
- compliance-agentへ渡せる
