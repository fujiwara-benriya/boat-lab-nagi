# 出力保存場所

分析サマリー、投稿案、note下書き、収集サマリーはこの `outputs/` 配下に保存します。

## 収集サマリー

```text
outputs/collection/YYYY-MM-DD/race-results-summary.md
outputs/collection/YYYY-MM-DD/pdf-collection-summary.md
```

## 統計サマリー

```text
outputs/statistics/YYYY-MM-DD/official-resultlist-statistics.json
outputs/statistics/YYYY-MM-DD/official-resultlist-statistics.md
```

## 投稿・note下書き

```text
outputs/draft-sample.md
outputs/posts/
outputs/note/
```
